SandyFlo Privacy Policy

Effective November 1, 2026

SandyFlo is a private desktop app that runs on the user's own computer. This policy explains what Google user data SandyFlo accesses when the user connects Google Calendar, and what it does with that data. The developer of SandyFlo operates no servers and receives no data from the app.

Google data SandyFlo accesses

SandyFlo requests one permission: https://www.googleapis.com/auth/calendar.app.created. This lets it create a secondary calendar named "SandyFlo Maintenance" and manage events in calendars it created. It cannot see or change the user's other calendars or events, and it does not request access to email, contacts, files, or any other Google data.

From Google, SandyFlo receives only:

  • OAuth tokens that let it keep the connection active.
  • The ID of the calendar it creates and the IDs of the events it adds, so it can update or remove those events later.

Data SandyFlo sends to Google

For each maintenance task or recurring schedule, SandyFlo sends one calendar event containing only:

  • A title made of the task name and a property nickname, such as "Gutter cleaning – Duplex A".
  • The due date and, for recurring tasks, a repeat rule.
  • Reminder times.
  • The fixed description "Scheduled in SandyFlo".

SandyFlo never sends street addresses, financial records, transaction details, costs, notes, documents, or contractor names or contact details to Google. Before sending an event, it refuses any title that appears to contain a street address or a long number.

How Google data is used

SandyFlo uses Google data only to create, update, and delete maintenance reminders in the "SandyFlo Maintenance" calendar at the user's request. It does not use Google data for advertising, analytics, profiling, or training artificial intelligence or machine learning models.

Storage and security

OAuth tokens and the OAuth client credentials are stored only on the user's computer, encrypted with the operating system's secure storage (the macOS Keychain). Calendar and event IDs are stored in SandyFlo's local database on the same computer. None of this data is stored anywhere else.

Sharing

SandyFlo does not share, sell, or transfer Google user data to anyone. Data received from Google is not sent to any other service.

SandyFlo's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access and deleting data

  • In SandyFlo, open Calendar and click Disconnect. This revokes SandyFlo's access and deletes the stored tokens and credentials from the computer. Check "Also delete the SandyFlo calendar from Google" to remove the calendar and its events too.
  • Access can also be removed at any time from the Google Account permissions page. The "SandyFlo Maintenance" calendar can be deleted in Google Calendar settings.

Changes

If SandyFlo's use of Google data changes, this policy will be updated and the effective date above will change.
