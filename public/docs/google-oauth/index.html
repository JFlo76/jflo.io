SandyFlo

A private desktop app for tracking household and rental property expenses, budgets, and maintenance.

SandyFlo runs entirely on one computer. It is a personal tool, not a public service: there are no accounts to create, no servers, and no downloads offered here.

What it does

  • Imports bank statements and categorizes transactions for budgeting and tax preparation.
  • Tracks rental property expenses, budgets, receipts, and contractors.
  • Schedules recurring preventative maintenance, such as gutter cleaning or smoke detector tests.

How it uses Google Calendar

If the user chooses to connect Google Calendar, SandyFlo creates one separate calendar named "SandyFlo Maintenance" and adds maintenance reminders to it, so Google can send reminders to the user's phone and email. SandyFlo can only see and change the calendar it creates. It cannot read or change any other calendar, and it does not access email, contacts, or other Google data.

Each calendar event contains only a task name, a property nickname, a date, a repeat rule, and reminder times. The connection can be removed at any time from within SandyFlo or from the Google Account permissions page.
